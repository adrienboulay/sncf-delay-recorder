lateproof
API pour agents · x402

Le conseil de trajet en direct, payé à l'appel.

Une appli, un assistant ou un agent IA demande à LateProof la meilleure façon d'aller de A à B, maintenant. Pas de compte, pas de clé d'API : chaque appel coûte 0,01 USDC, payé sur Solana avec le standard ouvert x402 (HTTP 402).

Comment ça marche

  1. L'agent appelle GET /advice?de=…&vers=….
  2. LateProof répond 402 avec ses conditions dans l'en-tête PAYMENT-REQUIRED : 0,01 USDC, réseau Solana, adresse du destinataire.
  3. L'agent signe le transfert d'USDC et rappelle avec PAYMENT-SIGNATURE.
  4. Le paiement est vérifié, le conseil calculé avec les données SNCF et Île-de-France Mobilités du moment, puis réglé sur Solana. La réponse porte la transaction (PAYMENT-RESPONSE).

Si le conseil ne peut pas être calculé, rien n'est prélevé : le règlement n'a lieu qu'une fois la réponse prête. Les frais de réseau en SOL sont payés par le facilitateur x402.

Appelle l'API sans payer, depuis ton navigateur. Tu obtiens les vraies conditions que le serveur envoie aux agents.

Pour un agent (Node.js, bibliothèques x402 officielles)


import { wrapFetchWithPayment } from "@x402/fetch";
import { x402Client } from "@x402/core/client";
import { ExactSvmScheme } from "@x402/svm/exact/client";
import { createKeyPairSignerFromBytes } from "@solana/kit";

const signer = await createKeyPairSignerFromBytes(secretKey);   // un portefeuille avec quelques USDC
const client = new x402Client();
client.register("solana:*", new ExactSvmScheme(signer));
const pay = wrapFetchWithPayment(fetch, client);

const r = await pay("…/functions/v1/advice?de=Paris Gare de Lyon&vers=Lyon Part-Dieu");
console.log((await r.json()).conseil);

        
Démonstration sur Solana devnet (USDC de test). Code source : supabase/functions/advice et x402/agent.mjs dans le dépôt public.
